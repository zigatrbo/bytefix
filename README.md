# ByteFix

Študentski projekt pri predmetu KIDS: predstavitvena spletna stran izmišljenega podjetja za servis računalnikov in IT podporo.

## Podjetje
ByteFix je izmišljeno slovensko podjetje, ustanovljeno leta 2024 v Mariboru. Posameznikom in manjšim podjetjem pomaga pri diagnostiki in popravilu računalnikov, nadgradnji komponent, namestitvi programske opreme ter vsakodnevnih tehničnih težavah. Njegova vizija je zagotoviti razumljivo, zanesljivo in dostopno IT podporo ter s popravilom in nadgradnjami podaljševati življenjsko dobo naprav.

## Načrt spletne strani
- **Domov:** predstavitev podjetja in glavnih storitev.
- **Storitve:** diagnostika, servis, nadgradnje in IT podpora.
- **Cenik:** informativne cene izmišljenih storitev.
- **O nas in kontakt:** zgodba, ekipa in kontaktni obrazec.

Obseg projekta je predstavitvena stran v HTML in CSS. Kontaktni obrazec je lahko prikaz vmesnika; pošiljanje sporočil ali sistem rezervacij nista del začetnega obsega.
